# Yang Xiao Lab

Website for the Yang Xiao Lab at the Medical College of Wisconsin.

Visit the site locally by opening `index.html` in a browser.

## Overview

This project is a static lab website built with HTML and CSS. It includes:

- Home page
- Research section
- PI profile
- People page
- Publications
- Contact information

## Files

- `index.html` — main site content and styling
- `Home_Page_topPanel.jpg` — homepage banner image
- `Research_01.png`, `Research_02.png`, `Research_03.png` — research figures
- `Yang_headshot.jpg` — PI headshot

## Local preview

Open `index.html` directly in a browser, or run a simple local server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a lightweight static website intended for easy customization and deployment on GitHub Pages or any static hosting service.
